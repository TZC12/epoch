## 一、研究结论如何改变了做法

三份调研（产品范式 / GitHub 可复刻清单 / 现有资产盘点）里，有三条直接推翻了"想当然"的方案：

**Cue 不是 chat-first。** cueai.app 的骨架是「说一句 → 生成一张可编辑的多日计划工件 → 用户在**产物上**改，而不是在对话里改」，主动插话只做一件事（到点提醒）。所以 v2 的首屏不是一根输入框，而是**一个判断 + 可采纳的提案卡**。另一个同名 heycue.io 是热键浮层，进一步说明"agent 感"不靠聊天窗。

**Grok Bot 的 agent 感来自可见的工作轨迹与交付物**，不是打字动画。因此提案卡带一条真的会走 pending → running → done 的步骤条，而不是一个假的 spinner。

**LibreChat 的 parts 模型**（assistant 回复=有序事件数组，每个工具调用带自己的状态）被采纳成 `TraceStep[]`。这是"agent"与"聊天框"的分界线，且纯前端零成本。

另外两条来自开源盘点的语义被直接搬进推导逻辑：Loop/uhabits 的「漏一天不等于连击死掉」（`habit-carry` 提案的措辞与判据就是它），fsrs/ts-fsrs 的「状态即数据」（下一步替换 Leitner 的预定方向，见 §五）。

## 三、设计基线（白卡 + 墨线 + blob）

`src/v2/v2-tokens.css` 三条规矩，验收脚本逐条盯：

1. **blob 永远不做文字底**。`#2F6BFF` 上放白字只有 4.4:1、放黑字只有 3.4:1，两边都过不了正文级——与其调一版勉强过的色，不如规定它只承载形状。角色填充、状态徽标（里面是图标）、进度色块、插画里那一块形，都可以是 blob；任何文字都不行。
2. **墨线一律 1.8**（与 `main.tsx` 的 `LucideProvider strokeWidth` 同一个真值），圆头圆角。
3. **卡片只有一种**（`.v2-card`：白面 + 1px 描边 + 极轻投影），不允许多层卡片样式。

签名细节是**实心墨影**——参考图里时钟、握手下面那块黑，是这套风格区别于普通"卡片列表"的地方，做成 `--v2-shadow-ink` 与 `.v2g-shadow`。

角色（`src/v2/Mascot.tsx`）：墨线轮廓 + 单色 blob 填充 + 白眼球墨瞳孔，6 个姿态（idle/think/propose/done/no/err）。**姿态同时换轮廓、眼睛形状和动效**，颜色只是加强——色盲与暗色下仍可读。尺寸只允许 24 / 48 / 72 三档，24 档不画眼睛（太小会脏）。

## 四、Agent 壳与接缝

`src/v2/agent/model.ts` 做**真实推导**：提案的每一个数字都来自当前 store（到期词数、最低盒、今天主任务数、昨天是否漏卡、近 3 天打卡），没有一条是编的；只出语义码，中文在 `src/v2/i18n-v2.ts`。

`src/v2/agent/briefing.ts` 是**唯一接缝**：现在是本地规则 + 假时长的事件流，接真 GLM 时只改这个文件，`BriefEvent` 形状不变、调用方一行不动。三条约束写在该文件头部：模型只能提名，落地仍走 `applyProposal`；校验不过不许写库；`AGENT_SOURCE` 常量驱动界面上的来源徽标（现在显示「本机规则」）。

**诚实性**是这一版的产品决策而不是工程细节：首屏那颗「本机规则」徽标明确告诉用户现在没有模型在跑。

其他与全站一致的规矩：采纳=即时生效 + 撤销 toast（`applyProposal` 返回 undo 闭包，写库全走既有 actions，不新建第二套 AI 数据）；拒绝=记账，同类否两次才闭嘴（一次误触不永久静音）；步骤没跑完时「就这么办」是 disabled。

## 五、下一步（按优先级）

1. **Flow 3「一句话 → 多日工件」**：Cue 的核心机制，目前只有入口没有实现。
2. **Leitner → FSRS**：直接依赖 `ts-fsrs`（MIT，纯函数），把 `LearnWord` 的 `box/due` 扩成 `stability/difficulty/state/due` + review log；有了它，agent 才能说"这张 4 天后会忘"。
3. **习惯的「N 次/M 天 + 断签缓冲」**：把 `schedule.ts` 的 streak 从"连续自然日"改成"应完成日序列"，`skipped` 记为缓冲而非清零。
4. **建议 chips 由数据生成**（现在 ask bar 是静态文案）。
5. **接真模型**（只改 `briefing.ts`）+ 通知/晨间简报时段授权。
6. 已知缺口：v2 一键清单没有左滑删除（旧页有）；`PhysicsConfetti` 的"最后一个待办勾掉"还没接回 v2（需要先把 `HomePage` 里的 `celebrateIfCleared` 抽成共享模块）；工具面底部保留旧页为 tabbar 预留的空高。
